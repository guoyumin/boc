# BOC · 苏黎世血染钟楼桌游群管理

> 一个给苏黎世《血染钟楼》（Blood on the Clocktower）桌游群用的小型管理网站：记录每周活动的出席情况、保存板子图片与剧本 JSON、维护成就墙。

站点计划部署在 `https://boc.jiliguru.dev`。
